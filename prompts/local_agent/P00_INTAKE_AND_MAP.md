# P00 — Intake, Git safety, and map

Run the pack doctor and local bootstrap against the live repository. Read the
repository map, Git safety report, upgrade plan, package-layout detection,
metadata audit, and root-hygiene plan. Do not edit source code yet. Before any
mutating integration, create a named non-default branch or dedicated worktree and
checkpoint tracked changes. Stop if the repository kind is unknown, the worktree
is unsafe for mutation, or proposed target paths are ambiguous.
