# P03 — Merge into the live architecture

Use `pack_doctor.md` to separate safe additions from merge-required files. Verify
`git_safety.md` before copying anything. Integrate the smallest compatible change
into the repository's existing API, CLI, registry, test, and documentation
conventions. Never overwrite a path based on a stale plan, create a parallel
perspective package, or replace existing conductor/AGENTS content wholesale.
