\section{Model Parameters}

The following YAML configuration defines the transition matrices, costs, utilities, and subgroup characteristics for the five interventions:
\begin{enumerate}
    \item HPV Vaccination
    \item Smoking Cessation
    \item Hepatitis C Therapy
    \item Childhood Obesity Prevention
    \item Housing Insulation
\end{enumerate}
