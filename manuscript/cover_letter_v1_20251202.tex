\opening{Dear Editor,}

We are (I am) pleased to submit our manuscript entitled "\textbf{vop\_poc\_nz: A Python Framework for Distributional Cost-Effectiveness and Value of Perspective Analysis}" for consideration for publication in the \textit{Journal of Statistical Software}.

This paper introduces \texttt{vop\_poc\_nz}, an open-source Python package designed to address a gap in health economic evaluation: the quantification of structural uncertainty arising from the choice of analytical perspective. While guidelines increasingly recommend considering multiple perspectives (e.g., health system vs. societal), current software tools typically treat perspective as a static parameter. Our package operationalizes the "Value of Perspective" (VoP) metric, allowing researchers and decision-makers to estimate the opportunity cost of perspective misalignment.

Key contributions of our work include:
\begin{itemize}
    \item A comprehensive framework for Distributional Cost-Effectiveness Analysis (DCEA) in Python.
    \item The first software implementation of the Value of Perspective (VoP) metric.
    \item Integration of standard health economic methods (Markov modeling, PSA, VOI) with advanced equity analysis.
    \item Reproducible case studies based on real-world data from Aotearoa New Zealand.
\end{itemize}

We believe this software will be of significant interest to the health economics community and aligns well with the journal's focus on high-quality statistical software.

The source code is available at: \url{https://github.com/edithatogo/vop_poc_nz}.

We confirm that this manuscript has not been published elsewhere and is not under consideration by another journal.

Thank you for your consideration.

\closing{Sincerely,}
