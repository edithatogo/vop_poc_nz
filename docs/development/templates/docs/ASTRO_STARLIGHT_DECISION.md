# Astro/Starlight documentation decision record

Adopt Astro/Starlight only if it improves the public information architecture without weakening Python API reference generation.

Evaluate:

- stable versus experimental method labelling;
- automatic API extraction from Python docstrings;
- versioned method contracts and schemas;
- runnable tutorials and result-manifest links;
- search, accessibility, and static deployment;
- maintenance burden compared with the existing documentation stack.

Do not migrate the documentation framework merely for novelty. Record the benchmark and migration cost in conductor track C10.
